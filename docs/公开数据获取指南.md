# AquaDetective 公开数据获取指南

> 版本：v1.0  
> 制定日期：2026-08-20  
> 目的：指导团队查找、筛选、下载和登记水质预警与污染溯源所需的公开数据

## 1. 本阶段要找什么

采用“中国主场景 + 美国公开基准 + 模拟事件”的数据路线。

优先级如下：

| 优先级 | 数据 | 用途 | 当前目标 |
|---|---|---|---|
| P0 | 中国断面水质时序 | 国内场景、异常检测、趋势预警 | 先找到一套可下载的数据 |
| P0 | 河网及断面坐标 | 上下游关系和地图 | 覆盖中国目标流域 |
| P1 | 排污企业和排口 | 构建候选污染源库 | 目标流域上游 20-50 家 |
| P1 | 流量、水位和降雨 | 传播时间、稀释和面源解释 | 与水质时间范围重叠 |
| P1 | 美国完整关联数据 | 公开可复现的溯源基准 | 先做一个 HUC8 流域 |
| P2 | EEM 荧光数据 | 指纹匹配研究 | 本期可继续使用合成数据 |

## 2. 中国主数据集最低要求

优先寻找太湖流域或钱塘江流域数据。候选数据集达到以下条件才适合作为主数据：

- 至少 10 个监测断面；
- 至少连续 1 年；
- 至少日频，小时级或 4 小时级更好；
- 有监测时间、断面名称和经纬度；
- 至少包含 pH、溶解氧、氨氮、总磷、高锰酸盐指数中的 4 项；
- 有明确单位、数据来源和下载日期；
- 能保存原始文件，后续可以重复处理；
- 使用条款允许科研、比赛或项目展示。

只有月度数据时，可以作为趋势分析和展示数据，但不能作为突发污染预警的唯一依据。

### 2.1 希望包含的指标

| 统一编码 | 常见中文名 | 常见单位 | 备注 |
|---|---|---|---|
| `ph` | pH | 无量纲 | 注意传感器异常和有效范围 |
| `do` | 溶解氧 | mg/L | 低值也可能是异常 |
| `conductivity` | 电导率 | uS/cm | 单位可能为 mS/cm |
| `turbidity` | 浊度 | NTU | 降雨后可能快速升高 |
| `codmn` | 高锰酸盐指数 | mg/L | 不得直接映射为 COD |
| `cod` | 化学需氧量 | mg/L | 与 CODMn 分开保存 |
| `ammonia_n` | 氨氮 | mg/L，以 N 计 | 核对是否标注 NH3-N |
| `tp` | 总磷 | mg/L | 湖库和河流限值不同 |
| `tn` | 总氮 | mg/L | 部分自动站可能缺失 |
| `temperature` | 水温 | 摄氏度 | 用于季节基线 |

## 3. 中国数据从哪里找

### 3.1 官方水质数据

1. [生态环境部全国地表水水质月报](https://www.mee.gov.cn/hjzl/shj/dbsszyb/)

   适合长期趋势、断面达标情况和官方引用。通常为 PDF 或附件表格，频率较低。

2. 国家地表水水质自动监测实时数据发布系统

   由中国环境监测总站相关系统发布。通过“中国环境监测总站 国家地表水 自动监测 实时数据”搜索官方入口，重点查看是否提供历史查询、导出或开放接口。

3. [生态环境数据中心](https://datacenter.mee.gov.cn/)

   搜索“地表水”“重点流域”“水质断面”“污染源”等主题。

4. 各省市生态环境局和政府开放数据平台

   优先搜索：

   ```text
   地区名 + 地表水监测数据
   地区名 + 断面水质 + 开放数据
   地区名 + 自动监测站 + 历史数据
   地区名 + 重点排污单位 + 在线监测
   ```

   地方平台有时比全国平台更容易取得历史明细。

### 3.2 科研数据平台

1. [国家地球系统科学数据中心](https://www.geodata.cn/)
2. [国家青藏高原科学数据中心](https://data.tpdc.ac.cn/)
3. [国家生态科学数据中心](https://www.nesdc.org.cn/)
4. [Science Data Bank](https://www.scidb.cn/)

建议搜索：

```text
太湖 水质
钱塘江 水质
河流水质监测
湖泊 氮磷
地表水 时间序列
流域 水文 水质
```

科研数据必须同时保存论文或数据说明、DOI、许可和引用方式。

### 3.3 污染源和企业数据

1. 全国排污许可证管理信息平台公开端；
2. 地方生态环境局重点排污单位名录；
3. 地方污染源自动监控信息公开平台；
4. 企业排污许可证、环境影响评价和自行监测报告。

第一期只整理目标流域内的企业，建议字段：

| 字段 | 必需性 |
|---|---|
| 企业名称、统一社会信用代码 | 必需 |
| 行业和生产类型 | 必需 |
| 企业或排口经纬度 | 必需 |
| 排口名称和去向水体 | 推荐 |
| 许可污染物和许可限值 | 推荐 |
| 许可证编号和有效期 | 推荐 |
| 数据来源页面 | 必需 |

公开页面没有批量下载功能时，先人工整理 20-50 家，不要未经许可持续爬取。

### 3.4 河网、降雨和水文

- [HydroRIVERS](https://www.hydrosheds.org/products/hydrorivers)：全球河网；
- [MERIT Hydro](https://hydro.iis.u-tokyo.ac.jp/~yamadai/MERIT_Hydro/)：流向和汇水区；
- [OpenStreetMap 中国区下载](https://download.geofabrik.de/asia/china.html)：河流和地理要素；
- [中国气象数据网](https://data.cma.cn/)：气象站和降雨数据；
- [Copernicus Climate Data Store](https://cds.climate.copernicus.eu/)：ERA5-Land 全球降雨；
- 水利部、流域管理机构和地方水文部门公开公报：流量、水位和水资源数据。

## 4. 美国公开基准怎么找

建议首个基准选择 Cuyahoga River 流域，HUC8 编码为 `04110002`。

### 4.1 水质观测

- [EPA Water Quality Portal](https://www.waterqualitydata.us/)
- [WQP Web Services 文档](https://www.waterqualitydata.us/webservices_documentation/)

建议时间范围先取 2018 年至今，下载站点和结果两个层级的数据，保留机构、方法、质量标志、检出限和单位。

### 4.2 流量和水位

- [USGS Water Data](https://waterdata.usgs.gov/)

寻找位于同一流域且与水质站相邻的站点，优先下载 discharge、gage height 和 water temperature。

### 4.3 企业、排口和排放记录

- [EPA ECHO Data Downloads](https://echo.epa.gov/tools/data-downloads)

需要的数据包括设施坐标、NPDES 许可证、排口、许可污染物和 DMR 排放记录。DMR 超许可只能作为候选证据，不能直接当作下游污染真值。

### 4.4 河网

- [NHDPlus High Resolution](https://www.epa.gov/waterdata/nhdplus-high-resolution)

下载覆盖目标 HUC8 的河网，保留 `COMID`、上下游连接、河段长度、流向和汇水区。后续把 WQP、USGS 和 ECHO 坐标吸附到 `COMID`。

## 5. EEM 数据怎么找

- [OpenFluor](https://openfluor.lablicate.com/)：用于查询 PARAFAC 荧光组分；
- Zenodo、Figshare、Science Data Bank：搜索 `excitation emission matrix wastewater`、`EEM river water`、`三维荧光 废水`；
- 水质和环境工程论文的 supplementary data。

EEM 数据可用的最低条件：

- 有完整激发波长和发射波长坐标；
- 有原始或预处理后的二维矩阵；
- 说明仪器、扫描步长和散射去除方法；
- 有样品类型或来源标签；
- 有多个样本，而不是论文中的一张图片。

OpenFluor 组分不能直接当作“一厂一谱”的企业指纹。找不到满足条件的数据时，本期继续使用合成 EEM，并明确标识。

## 6. 数据集筛选评分

找到候选数据后按 100 分评分：

| 维度 | 分值 | 判断标准 |
|---|---:|---|
| 来源和许可 | 20 | 官方或有 DOI，许可明确 |
| 时间跨度和频率 | 20 | 至少一年且日频以上 |
| 空间信息 | 15 | 有坐标、断面和流域信息 |
| 指标完整性 | 15 | 至少 4 个主要水质指标 |
| 可关联性 | 15 | 能关联河网、水文或企业 |
| 可复现获取 | 10 | 可下载文件或有稳定 API |
| 数据质量 | 5 | 有质量标志，缺失和异常可解释 |

- 80 分以上：可作为主数据集；
- 60-79 分：作为补充或对标数据；
- 60 分以下：只用于展示，不进入核心评测。

## 7. 下载和保存要求

目录约定：

```text
data/raw/<dataset_id>/         原始文件，下载后不修改
data/interim/<dataset_id>/     解压、字段整理和空间匹配结果
data/processed/<dataset_id>/   标准化数据
metadata/<dataset_id>.json     来源和许可元数据
```

每次下载后执行：

```powershell
Get-FileHash <文件路径> -Algorithm SHA256
```

不得在 `raw` 目录直接用 Excel 修改并覆盖原文件。

## 8. 找到数据后交付什么

每个候选数据集提交以下内容：

1. 数据来源页面链接；
2. 一份原始样例文件；
3. 数据说明或字段表；
4. 时间范围、频率、站点数和指标列表；
5. 是否包含坐标和质量标志；
6. 下载方式以及是否需要账号；
7. 许可、引用或使用限制；
8. 文件大小和 SHA256；
9. 你对数据完整性的简短判断。

暂时不要投入大量时间清洗。先交付样例和元数据，由团队确认能够进入系统后再批量下载。

## 9. 推荐执行顺序

1. 先查太湖和钱塘江，分别找出 2-3 个候选水质数据集；
2. 用本指南评分，选择一个中国主数据集；
3. 补齐同区域河网和降雨；
4. 人工整理上游 20-50 家排污企业；
5. 同时下载美国 Cuyahoga 流域的少量样例，验证四类数据能否关联；
6. 团队评审样例后，再进行完整下载和导入器开发。

第一轮只需找样例，不要求立即收齐全部历史数据。
