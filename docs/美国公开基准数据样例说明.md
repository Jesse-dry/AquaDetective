# 美国公开基准数据 · Cuyahoga 流域样例说明

> 状态：样例已下载并完成**河网关联导入器原型**，四类数据已通过 COMID 打通。
> 下载/处理日期：2026-08-21　|　目标流域：Cuyahoga River，HUC8 `04110002`（HU4 `0411`）

## 1. 概览

| 数据 | dataset_id | 来源 | 规模 | 用途 |
|---|---|---|---|---|
| 水质观测 | `usgs_wqp_cuyahoga` | Water Quality Portal | 1889 地表水站 / 76755 观测（2018–2024） | 异常检测、趋势预警 |
| 流量/水位/水温 | `usgs_nwis_cuyahoga` | USGS NWIS | 112 测站 / 44306 逐日值（2018–2024） | 传播时间、稀释解释 |
| 设施 + 排放 | `epa_echo_cuyahoga` | EPA ECHO | 231 NPDES 设施 / FY2024 DMR 56239 + 违规 39425 | 候选污染源库、超许可证据 |
| 河网 | `nhdplus_hr_cuyahoga` | NHDPlus HR | 17915 网络河段（Flowline） | COMID 拓扑、上下游吸附 |

## 2. 河网关联导入器（已落地）

`scripts/build_flow_network.py` 完成三件事，产出可复现的空间/拓扑结果：

1. **读河网**：解压 GDB，`NHDFlowline`（几何，EPSG:4269）按 `NHDPlusID` 关联 `NHDPlusFlowlineVAA`（FromNode/ToNode 拓扑）→ 17915 条网络河段；
2. **坐标吸附**：2233 个站点（WQP 1890 / USGS 112 / ECHO 231）吸附到最近河段 `COMID`（2131 个 ≤500m，102 个 >500m，全部命中）；
3. **上下游拓扑**：`networkx` 有向图 17549 节点 / 17719 边（FromNode→ToNode 为水流方向），并给出**每个监测站上游的 NPDES 设施数**（溯源候选）。

结果示例：Cuyahoga 河口站（Cleveland）上游 185 个设施；中游 Old Portage（Akron）上游 65 个——沿流域梯度递减，符合预期。

**产物**：
- `data/interim/nhdplus_hr_cuyahoga/` — `flowlines.geojson`、`sites_snapped.csv`
- `data/processed/cuyahoga_network/` — `flow_edges.csv`、`flow_network.pkl`（networkx 图）、`stations_upstream_facilities.csv`

**复现**：`backend/.venv/Scripts/python.exe scripts/build_flow_network.py`（依赖 `geopandas`+`pyogrio`，已加入 `pyproject.toml` 的 `data` 可选依赖组）。

## 3. 关键结论

- **水质**：连续传感器站提供 pH/溶解氧/水温/电导高频数据；营养盐（氨氮、硝氮、亚硝氮、总磷）为手工采样。
- **流量水位**：112 站中多数有流量（00060，41043 值），部分站有水位/水温。
- **设施排放**：231 个 NPDES 设施中 138 个在 FY2024 有 DMR（56239 条）；主要污染物 Solids/Nitrogen/BOD/pH/Flow/Phosphorus/E.coli/Mercury；另有 39425 条违规记录。
- **河网**：NHDPlus HR 用 `NHDPlusID`（等价于 NHDPlus V2 的 COMID）作网络键。

## 4. 下载方式（可复现）

- ECHO 设施：`https://echodata.epa.gov/echo/cwa_rest_services.get_facilities?output=JSON&p_huc=04110002`（**注意**：经度需另用 `get_facility_info?...&qcolumns=2,24,25` 显式请求，FacLong=25）
- ECHO DMR/违规：`https://echo.epa.gov/files/echodownloads/NPDES_by_state_year/OH_*.zip`（全州，经 `scripts/filter_dmr_cuyahoga.py`、`filter_violations_cuyahoga.py` 过滤到 HUC8）
- NHDPlus HR：`https://prd-tnm.s3.amazonaws.com/StagedProducts/Hydrography/NHDPlusHR/Beta/GDB/NHDPLUS_H_0411_HU4_GDB.zip`
