## ① 开场与问题(1 min)

**话术**:
> 水污染事件发生后,「断面异常 → 锁定排放源」之间的链路往往靠人工经验,
> 存在滞后、主观、难量化三大痛点。AquaDetective 把这条链路工程化:
> 多智能体协作完成「异常检测 → 预警 → 侦探式溯源 → 指纹比对 → 法规 → 处置 → 报告」闭环。

**要点**:点出痛点,定义系统边界(辅助决策,非执法认定)。

---

## ② 架构总览(1.5 min)

**话术**(切架构图/README):
> monorepo 三层:后端 FastAPI + LangGraph、前端 React、docs 设计文档。
> 后端分四层:
> - **数据层**:流域配置 + 90 天 15 分钟级时序 + 3 条预置事件,含 Ground Truth
> - **计算引擎**(`engine/`):**纯函数、无 LLM、无 I/O**,异常检测/高斯烟团扩散/EEM+污染物双指纹/拓扑溯源/昼夜规律
> - **Agent 层**:LangGraph 状态机,parse → 假设 → 校核(循环路由)→ 结论 → 法规 → 处置 → 报告
> - **API 层**:REST + WebSocket,调查在后台线程跑图,stream 经 asyncio.Queue 推送

**核心铁律**(加重语气):
> 一切数值计算只走 `engine/` 确定性纯函数,LLM 只做推理编排与自然语言表达。
> 这是工程可信度的根基——结果可复现、可单测、可审计。

## ③ 现场 demo(4 min)

### 准备
```
# 终端1(后端)
cd backend && python -m app.data.seed && uvicorn app.main:app --port 8000
# 终端2(前端)  http://localhost:5173
```

### 步骤

**3a. 触发事件(30s)**
> 大屏首页告警面板,事件1(耀光金属夜间偷排,电镀废水,六价铬+COD)。
> 点击触发调查,WebSocket 推理流实时上屏。

**3b. 推理流(1.5 min)**
> 左侧地图高亮异常断面,右侧推理流逐条推送:
> - `parse_event`:解析事件线索(断面/指标/超标倍数)
> - `generate_hypotheses`:列出上游嫌疑企业(按衰减系数排序)
> - `verify_hypotheses`(循环):对每个假设跑 3 类证据校核
>   - EEM 指纹比对(余弦+皮尔逊)
>   - 污染物比例向量匹配(真实许可证指纹注入)
>   - 排放规律分析(夜间活跃/周期性)
> - `conclude`:锁定真凶 + 置信度
> - `compliance` + `responder` + `reporter`:法规引用 + 处置建议 + 报告生成

**3c. 指纹锁定(1 min)**
> 点开指纹比对面板:现场 EEM 矩阵 vs 企业指纹库,余弦相似度可视化。
> 强调:指纹库已注入**真实许可证主要污染物年排放量限值**(非合成值)。

**3d. 报告(1 min)**
> 报告页:Markdown 溯源报告,含证据链、法规条款、处置建议。
> 点回放页:可重新播放整个推理过程。

## ⑤ 诚实声明与收尾(1.5 min)

**话术**(关键,体现工程素养):
> 我们对真实数据溯源结果做了 4 视角对抗式核验:
> - 拓扑核验:confirmed(0.95),NEXT_DOWN 直连无断裂
> - 异常核验:confirmed(0.78),CUSUM 检出真实孤立
> - 时空一致性:指出 4.6h 是距离排序分非因果证据

**诚实降级**:
> 据此我们把命中从「溯源命中」降级为「候选命中」——
> 距离最近 + 行业匹配 + 拓扑核验通过,但未与污水厂出水在线监测做交叉验证,不构成确证因果。
> 命中的锡北污水厂许可已注销,指纹用同行业真实代理,已如实标注。

**收尾**:
> 本系统是辅助决策工具,不是污染事件认定。真实数据用于算法验证,不替代执法。
> 完整闭环 + 诚实标注,是我们对工程严谨的基本态度。

## 问答预案

**Q: 指纹分数为什么低(0.13)?**
> 因为断面检出氨氮异常(观测向量氨氮主导),而污水处理厂排放指纹以 COD 为主。
> 分数低是诚实结果——说明仅凭指纹不足以致信,拓扑+行业匹配仍是主要证据。系统如实呈现,不强凑高分。

**Q: 为什么要做对抗核验?**
> LLM 易对自身结果过度自信。我们用独立视角(拓扑/异常/候选/时空)交叉核验,
> 发现时间尺度矛盾后主动降级,避免误导。这是工程素养而非演示技巧。

**Q: 真实数据溯源能用于执法吗?**
> 不能。许可是辅助决策工具,真实断面异常归因属候选命中,需现场采样+在线监测交叉验证才能认定。
> 系统价值在「把人工经验链路工程化、可审计、可复现」。

**Q: 核心铁律(数值不走 LLM)的意义?**
> 可复现:同输入同输出;可单测:22 个引擎测试;可审计:LLM 只解释,不产数,规避幻觉。
> 这是把 LLM 用在「该用的地方」(推理编排),而非「不该用的地方」(数值计算)。
